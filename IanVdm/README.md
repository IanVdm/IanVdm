# IanVdm.github.io

This repository contains a Next.js portfolio website built with TypeScript and Tailwind CSS.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Lint the code:

```bash
npm run lint
```

## Notes

- The site uses a dark, tech-inspired theme with smooth scrolling navigation.
- Sections include the intro, about, current work, featured projects, stack, contact, and footer.
- Update the contact details and project content in `src/app/page.tsx`.
